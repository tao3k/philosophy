This note distinguishes what mathematical proof, bounded model checking, testing, simulation, and runtime observation can each establish.

[[file:../README.org][English navigation]] · [[file:../30-reflections/30.30-simulation-is-not-prediction.org][corresponding reflection]]

* Context

Each method has explicit models, assumptions, bounds, and counterexample semantics. Conclusions carry authority only within those boundaries.

* Interpretation Boundaries

Proof within a model is not real-world correctness; no failure within a bounded horizon is not global absence of failure.

* Influence

It enters the simulation-is-not-prediction reflection and supports the proportional-assurance Charter.

* Interpretation Chain

Historical source → Tao3k modern interpretation → [[file:../30-reflections/30.30-simulation-is-not-prediction.org][corresponding reflection]] → possible thematic Charter. The direction preserves the distinction between source, interpretation, and norm; it must not be reversed into a claim that the source proved the current architecture.
