* Principle
:PROPERTIES:
:CUSTOM_ID: cross-repository-principle-en
:END:

This map projects the seven thematic principles into engineering review conditions. It does not freeze
today's repository structure: an implementation may be replaced without changing the philosophy; a change
to normative meaning must return to the lifecycle of the corresponding Charter.

* Normative Requirements

| Principle ID | Engineering property | Unacceptable substitute |
|--------------+--------------------------------+-------------------------|
| PHIL-EPI-001 | Preserve sources, observations, inferences, and unknown frontiers | Treating model confidence or fluency as fact |
| PHIL-TEMP-001 | Distinguish event time, observation time, order, and causal claims | Inferring causality directly from correlation or log order |
| PHIL-AGENCY-001 | Preserve human intent, refusal, override, and appeal | Replacing human value and consent with an optimization metric |
| PHIL-AUTH-001 | Prove actor, scope, validity, and policy authority before action | Treating tool availability as permission to act |
| PHIL-ASSURE-001 | Increase assurance with irreversibility, impact radius, uncertainty, and authority scope | One confidence threshold for every action |
| PHIL-RESIL-001 | Prefer rollback, isolation, degradation, observation, and retained options | Proving only the success path |
| PHIL-PRAXIS-001 | Return outcomes through receipts and re-observation to the knowledge system | Treating an execution return code as a learning loop |

* Review Questions

Reviewers must answer: which Principle ID is cited; what semantics the implementation preserves; which
parts remain candidates; where the evidence lives; which counterexample or failure invalidates the claim;
whether an implementation replacement preserves normative meaning; and, if meaning changes, whether
Governance has reconsidered the corresponding existing Charter Principle using challenge or Reflection
evidence and recorded an explicit retained, revised, superseded, or withdrawn decision. Challenge is an
event and evidence, not a Principle status.
