* 问题
:PROPERTIES:
:CUSTOM_ID: philosophy.reflection.30.98-living-with-the-unpredictable-cn
:END:
人生中的一些风险可以估计：已知账单、合同期限、常见收入波动。另一些变化只有模糊轮廓，甚至会在发生后改变我们理解问题的语言。疾病、关系破裂、战争、技术替代、照护中断或制度变化，可能同时改变资源、责任、目的与谁能够参与决定。

如果模型只能处理已经列出的分支，AI 面对这些变化时应做什么？它既不能假装已经预测，也不能因为无法穷尽未来而停止一切行动。本篇追问：怎样在未知仍然真实存在时准备、应对和恢复，并保留重新理解生活的能力？
* 论证
不可预测不是一个等待填入概率的空格。有时我们缺少发生概率，有时连候选事件、影响机制或评价尺度都不完整。负责任的帮助首先要说清现在知道到哪一层，再决定什么可以准备、什么只能监测、什么需要在发生后重新判断。

** 风险、含混与惊异不是同一种不知道
下面的区分是工作语言，不声称所有处境都有唯一分类。一次惊异在被理解后可能成为以后可讨论的风险；一个看似可估计的风险也可能因制度或行为反馈而改变。

#+NAME: kinds-of-uncertainty-cn
| 处境 | 当前能够说明什么 | 适当的帮助 | 不应声称什么 |
|------+------------------+------------+--------------|
| 有界风险 | 候选结果与一部分频率或范围已有依据 | 比较暴露、设置相称余量、明确触发条件 | 数字精确就等于生活后果完整 |
| 含混 | 候选结果大致可见，权重或机制有争议 | 并列解释、寻找判别证据、避免过早收敛 | 选择一个分布就消除了争议 |
| 惊异 | 事件或意义超出当前表示 | 先稳定关键条件、记录新观察、重开问题框架 | 未被模型表示就不可能或不重要 |

[[file:30.50-unknown-as-first-class.org][把未知作为一等对象]] 不只是给字段加上 =unknown= 。如果系统随后仍按最完整的一条路径行动，未知没有真正改变判断。未知至少应限制不可撤回的自动行动，提示哪些承诺依赖尚未核实的前提，并保留接收新事实的入口。

** 准备不是把全部生活变成防御
缓冲有许多形态：现金与时间余量、可替代的照护、可信联系人、资料副本、可迁移的技能、组织的申诉渠道，以及能够停下来重新商议的关系。它们不能完全互换。钱不能自动替代照护者，联系人也不能弥补无权进入的服务。

准备还会消耗当下生活。无限储蓄可能取消学习与休息，永远保持退出可能会使有意义的承诺无法形成，持续监测则可能把焦虑和监控带进家庭。问题不是“缓冲越多越好”，而是：它保护什么脆弱条件，由谁负担，是否与损害规模相称，以及何时应被用于恢复生活而不是继续积累。

[[file:30.93-intertemporal-agency.org][跨时间主体性]] 因而既要求给未来留下判断能力，也要求未来的安全不能吞掉现在。一个人可以在理解后承担风险；系统的任务不是让人生零波动，而是避免把未说明的风险和不可承受的代价偷偷交给本人或他人。

** 中断发生时，先恢复判断条件
重大变化后的第一个问题未必是重新优化整个人生。睡眠、住所、照护、药物、通信、身份资料或免受即时伤害的空间，可能先决定当事人能否继续判断。此时帮助应从“选最优路径”转向“恢复最低限度的行动与理解条件”。

这不等于系统可以借紧急之名取得无限权限。越是压力高、时间短，越要区分：已经授权的常规处置、为了防止即时且严重损害所必需的有限行动，以及必须交还给有正当地位者的重大决定。无法取得完整说明时，应保留最少必要记录与事后复议，而不是把仓促决定包装成充分同意。

恢复也不等于回到事件前。失去的关系、能力、家园或职业可能无法复原。当事人可能需要建立一种不同但仍值得过的生活。把“恢复成功”定义为重新达到旧产出，会把哀伤、适应与新的目的误判为偏离。

** 状态变化不等于未来已经被列完
TLA+ 适合表达状态、允许的转移和需要重议的条件；它不能使未被想象的事件自动变成已知。下面的 Org Babel 片段只表达一条纪律：新观察造成中断时，不静默扩张承诺，而是进入稳定与重议。 =o= 是系统能够接收的一项新观察，并不证明所有事件类型已经枚举。[fn:tla-cn]

#+NAME: disruption-reconsideration-cn
#+CAPTION: 新观察先触发中断与重议；承诺只在显式重新判断中改变。该状态关系不是风险预测器。
#+begin_src tla :eval never :exports code
VARIABLES mode, observations, commitments, review_required

Init == /\ mode = "ordinary"
        /\ observations = {}
        /\ commitments = {}
        /\ review_required = FALSE

Unexpected(o) == /\ o \notin observations
                 /\ observations' = observations \cup {o}
                 /\ mode' = "disrupted"
                 /\ review_required' = TRUE
                 /\ UNCHANGED commitments

Stabilize == /\ mode = "disrupted"
             /\ mode' = "stabilizing"
             /\ UNCHANGED <<observations, commitments, review_required>>

Reconsider(next_commitments) ==
  /\ mode = "stabilizing"
  /\ review_required
  /\ mode' = "reconsidering"
  /\ commitments' = next_commitments
  /\ review_required' = FALSE
  /\ UNCHANGED observations
#+end_src

这段关系刻意不写“正确的新承诺是什么”。新承诺可能需要事实核实、当事人的新解释、受影响者参与以及外部支持。形式语言在这里约束推理顺序：事件前不偷看未来，事件后不沿用失效前提，也不把一次应急处置升级为永久授权。

** AI 的帮助分布在变化之前、之中与之后
变化之前，AI 可以检查单点依赖、帮助形成相称余量、说明哪些前提未经核实。变化之中，它可以整理事实、联系已授权支持、保护关键资料和减少认知负担。变化之后，它需要比较原假设与实际经历，辨认哪些目的仍成立、哪些关系或能力已经改变，并支持重新协商。

这三个阶段不能相互冒充。预演不是发生过，应急响应不是长期治理，事后叙事也不能证明当时本可预知。[[file:../40-sources/40.96-performative-prediction.org][施为性预测]] 还提醒我们：建议会改变人的行为和制度反应，因此一次预测失准可能来自资料不足、环境变化或预测参与改变了环境，不能只归咎于个人没有服从。

** 有些变化要求修改解释框架
一个人失去原职业后，问题未必只是“怎样尽快恢复收入”；能力变化后，目标也未必只是“恢复原功能”。事件可能显露过去被忽视的关系、伤害或愿望。[[file:../40-sources/40.97-transformative-experience-evaluability.org][转化性经验与可评价性偏差]] 提供了一个受争议但重要的提醒：发生之前难以评价的经验，不应因难以展示而被当作价值较低。

因此，事后更新不能只改余额和概率。还要允许当事人说：“原来的问题问错了”“我不再认可这项目的”或“以前没有进入模型的事情现在最重要”。AI 可以帮助比较这些新理由与既有责任，却不能把变化一律诊断为不稳定，也不能利用脆弱时刻重写一个人的长期目的。

** 个体韧性不能替制度免责
当医院、雇主、平台或公共服务存在单点失败，把更多准备任务交给个人可能只是转移责任。建议用户多存钱、多学习、多备份，不能替代机构提供连续服务、合理调整、纠错和救济。

个人准备仍有价值，但应标明约束的所有者：哪些能够由本人改变，哪些需要家庭协商，哪些应由组织承担，哪些需要公共或集体行动。[[file:30.97-shared-lives-and-responsibility.org][共同生活]] 意味着恢复资源不能总从最疲惫、最弱势或最少参与决定的人身上取得。

* 反例
第一，并非每次意外都需要重开人生目的。公交延误或一次普通支出可以由既有规则处理；频繁要求重新反思会增加负担。重议强度应与前提失效程度、后果和不可撤回性相称。

第二，紧迫情境有时无法等待完整参与。有限的应急行动可能合理，但这不能成为永久扩大权限的先例。需要说明必要性、范围、停止条件和事后补救。

第三，强调未知可能被用来拒绝任何承诺或证据。承认模型不完整，不等于所有判断同样无知；已有可靠依据仍应发挥作用，且错误主张不能用“未来不可预测”逃避反驳。

第四，“接受新的自己”可能被制度用于降低支持标准。尊重改变后的目的，不等于要求人适应本可避免的伤害或放弃可获得的治疗、便利、赔偿与改革。
* 暂定结论
与不可预测共处，不是预测全部事件，也不是把人生建成永不受损的系统。AI 应帮助人形成相称而多样的余量，在中断中先恢复行动与判断条件，并在新经验使旧前提失效时重新打开问题。恢复可以通向不同的生活，但不能让个人适应替机构责任、他人参与或现实救济消失。
* 升格条件
本篇仍是反思草稿。升格需要来自不同中断类型、资源条件、能力与家庭结构的自愿经验；需要检验应急行动与长期权限的界线、不同余量是否真实可获得，以及“重新判断”是否被系统用来诱导脆弱者。还需区分哲学上的状态纪律、实际应急流程与适用的法律或专业义务。TLA+ 片段通过语法或模型检查，也只能证明表达内部的一致性，不能证明现实风险已经覆盖。
